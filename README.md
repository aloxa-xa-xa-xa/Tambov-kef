# Тамбов Кэф — Android prototype 0.1.0

Первый минимальный исходный проект для Android (POCO/Xiaomi, Android 8+).

## Что есть сейчас
- отдельные поля для ручного ввода наблюдений «Эконом» и «Комфорт»;
- отображение последнего введённого наблюдения в приложении;
- GitHub Actions workflow для сборки debug APK и публикации APK как workflow artifact.

## Чего пока нет
- автоматического OCR/MediaProjection;
- карты и геокодирования;
- сервера и обмена данными водителей;
- истории на постоянном хранилище;
- плавающего окна поверх Яндекс Про.

Значения, введённые вручную, не являются официальными данными Яндекса.
Приложение не запрашивает логин, пароль, SMS-код или токены Яндекса.

## Сборка
В GitHub открой Actions → Android APK → Run workflow.
После успешной сборки скачай artifact `tambov-kaef-debug-apk`.
