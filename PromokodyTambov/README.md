# Промокоды Тамбов

Android-проект для поиска возможных промокодов в публичных источниках.

- Водители Яндекс Про
- Курьеры Яндекс Про
- Пассажиры Яндекс Go
- Фоновый поиск примерно раз в 12 часов и кнопка ручного запуска
- Уведомления о новых буквенно-цифровых совпадениях
- Без Tor

**Важно:** результаты поиска — только кандидаты. Приложение извлекает похожие на коды строки из сниппетов поисковой выдачи; оно не подтверждает, что код действующий, подходит Тамбову или конкретной категории. Проверяйте источник, срок и условия в официальном приложении.

Сборка запускается workflow Promokody Tambov APK. APK публикуется как artifact promokody-tambov-debug-apk.
